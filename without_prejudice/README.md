# Without Prejudice Quarantine Folder

Place all documents, emails, and draft agreements relating to settlement negotiations here.

### What belongs here:
1. **Draft Settlement Agreements / Severance Agreements**
2. **Letters / Emails marked "Without Prejudice"**
3. **Formal proposals made under Employment Rights Act 1996 s.111A** (or local pre-termination negotiation equivalents)
4. **Lawyer / Solicitor fee contribution correspondence**

### Why this is quarantined:
In employment law, settlement negotiations are strictly privileged. If an unrepresented worker accidentally quotes or attaches a "Without Prejudice" offer in an open grievance or tribunal submission, it can compromise the legal privilege and damage the case. The AI agent is strictly instructed to tag these documents as `[WP-XX]` and never include them in open evidence schedules.
